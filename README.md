# DevOps Production Project

A hands-on project demonstrating real-world DevOps practices.

## Application
Python Flask REST API.

## Endpoints
- / : Application information
- /health : Health check

## Technologies
- Python
- Flask
- Pytest
- Git
- Docker
- GitHub Actions
- Kubernetes
- Terraform
- Ansible
- Prometheus
- Grafana

## Run locally

Create virtual environment:

python3 -m venv venv

Activate:

source venv/bin/activate

Install dependencies:

python -m pip install -r requirements.txt

Start application:

python app/app.py

## Run tests

python -m pytest -v
python -m pytest -v
